DriftLoom sama sekali tidak menggunakan pustaka kerangka kerja Google, atau layanan API YouTube. DriftLoom hanya mengunakan informasi situs YouTube untuk mendapatkan informasi yang dibutuhkan. Oleh karena itu, DriftLoom bisa digunakan pada perangkat tanpa Layanan Google. Anda juga tidak membutuhkan akun YouTube untuk menggunakan DriftLoom, dan aplikasi ini sepenuhnya FLOSS.
