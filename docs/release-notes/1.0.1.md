DriftLoom 1.0.1 improves iPad navigation and sideloaded sharing.

- Sharing uses supported iOS extension APIs. The share sheet offers Copy link; paste in Search or the Home link box.
- The iPad tab bar remains accessible after submitting a search.
- Fixes compatibility when building with newer iOS SDKs.
- Adds iOS package tests, sharing UI checks and unsigned IPA verification to release checks.

**Installation:** download the unsigned IPA and use
[the sideloading guide](https://github.com/sk3llo/DriftLoom/blob/main/docs/install-ios.md).
You can also add the [public source](https://sk3llo.github.io/DriftLoom/) in SideStore or AltStore Classic to
install and update DriftLoom. No paid publisher account is required; free user accounts still need refreshing every seven days.
