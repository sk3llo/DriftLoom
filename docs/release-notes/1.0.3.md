DriftLoom 1.0.3 adds a Mac app and fixes a missing icon on iOS 15.

- **Mac (preview):** DriftLoom now runs on macOS 12 or later, on Apple silicon and Intel Macs. Download
  `DriftLoom-1.0.3-mac.dmg` and follow the
  [Mac install guide](https://github.com/sk3llo/DriftLoom/blob/main/docs/install-mac.md). Apple hasn't notarized
  it, so macOS asks you to allow it once.
- **iOS 15:** Play next in the video menus now shows its icon.
- **Android:** no changes besides the version number.

**Installation:** on iPhone and iPad, update through the [public source](https://sk3llo.github.io/DriftLoom/) in
SideStore or AltStore Classic (in SideStore, from DriftLoom's page in the source), or follow the
[sideloading guide](https://github.com/sk3llo/DriftLoom/blob/main/docs/install-ios.md). On Android, install the
APK over the previous version.
